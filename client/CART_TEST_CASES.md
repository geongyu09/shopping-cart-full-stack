# 장바구니 통합 테스트 케이스

`CartsSection` / `OrderConfirmSection` 기준 통합 테스트 케이스 정리.

## 실제 문구 / 검증 대상

| 상태              | 검증 대상                                                                         |
| ----------------- | --------------------------------------------------------------------------------- |
| 비어 있을 때      | `"장바구니에 담은 상품이 없습니다."`                                              |
| 에러일 때         | `"문제가 발생했습니다."` + `"잠시 후 다시 시도해 주세요."` (ErrorFallback 기본값) |
| 로딩 시           | 스켈레톤(`CartListSkeleton`) 노출 — **문구가 아님**                               |
| 주문 확인 클릭 시 | `"총 {N}종류의 상품 {M}개를 주문합니다."` + 총 금액                               |

---

## 테스트 케이스

### 진입 / 선택 상태

- [ ] 진입 시 전체 선택되어 있다 (localStorage가 비어 있을 때)
- [ ] 일부 선택 후 새로고침하면 그 선택이 유지된다
- [ ] 전체 해제 후 새로고침하면 전체 선택으로 복귀한다
- [ ] 전체 선택을 토글하면 선택/해제가 전환된다
- [ ] 일부 선택 후 전체 선택을 선택하면 전체 선택 된다
- [ ] 모든 아이템을 개별 선택하면 전체선택 체크박스가 checked 된다

### 가격 동기화

- [ ] 아이템 선택/해제 시 주문 금액/총액이 갱신된다
- [ ] 수량 변경(+/-) 시 주문 금액/총액이 갱신된다
- [ ] 선택 금액 100,000원 이상이면 배송비 0원, 미만이면 3,000원이다

### 삭제

- [ ] 아이템 삭제 시 목록에서 사라진다
- [ ] 선택된 아이템 삭제 후 전체선택 체크 상태와 가격이 올바르게 동기화된다

### 주문 확인 버튼

- [ ] 아무것도 선택하지 않으면 주문 확인 버튼이 disabled 된다
- [ ] 장바구니가 비어 있으면 주문 확인 버튼이 disabled 된다
- [ ] 주문 확인 클릭 시 선택한 상품 종류 수 / 총 수량 / 총 금액 문구가 표시된다
- [ ] 주문 확인 페이지의 "결제하기" 버튼은 항상 disabled 다

### 상태별 화면

- [ ] 장바구니가 비어 있으면 `"장바구니에 담은 상품이 없습니다."` 문구가 표시된다
- [ ] 에러 발생 시 `"문제가 발생했습니다."` / `"잠시 후 다시 시도해 주세요."` 가 표시된다
- [ ] 로딩 중에는 스켈레톤이 노출된다

### 기타

- [ ] CartHeading에 상품 개수(`data.length`)가 표시된다

## ⚠️ 점검 필요 (테스트 작성 전 코드 확인)

1. **삭제 시 `checkedItems` 미동기화** — `handleDelete`가 삭제된 id를 `checkedItems` / localStorage에서 제거하지 않음. `initialCheckedItems`는 `useState` 초기값으로만 쓰여 데이터 변경 시 재동기화되지 않음.
